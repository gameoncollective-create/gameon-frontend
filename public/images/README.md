# Image assets

Drop files here with these EXACT names and they'll show up on the site
automatically — no code changes needed.

## Logo
- `logo.png` (or rename and update the path in `src/components/Logo.jsx`)
  - Recommended: square-ish, transparent background, at least 80x80px
  - Used in the nav bar and footer

## Homepage hero
- `hero.jpg`
  - Recommended: landscape, at least 1920x1080px, a strong/dramatic action shot
  - This is the full-bleed background behind "Women's Football Intelligence"

## Athlete photos
- `athletes/vivian.jpg`
- `athletes/njeri.jpg`
- `athletes/akinyi.jpg`
  - Recommended: portrait orientation (taller than wide), at least 800x1000px
  - These appear on the homepage "Our Players" section, the Services page,
    and each athlete's individual profile page
  - The site automatically applies a black & white treatment via CSS —
    upload full color, no need to pre-edit them

## If a file is missing
The site is built to degrade gracefully — if any of these files aren't
here yet, that spot just shows the current placeholder (gradient block or
default logo mark) instead of a broken image icon. Add files whenever
they're ready; no other changes needed.
